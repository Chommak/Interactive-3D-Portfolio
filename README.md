# Interactive 3D Portfolio — Anime Diorama (เวอร์ชันฉาก)

เวอร์ชันนี้สำหรับส่งรอบแรก "ลิงก์ + ฉาก" — มีฉาก 3 มิติครบเกณฑ์แต่ยังไม่มีระบบ Picking
(ระบบ Picking + แผงข้อมูล จะเพิ่มในรอบส่ง 29.09.2026 ซึ่งอยู่ในโฟลเดอร์หลักของโปรเจกต์)

ฉากเป็นเกาะลอยน้ำสไตล์อนิเมะสร้างด้วย Three.js ล้วน (ไม่ใช้โมเดลภายนอก)
มีเซลเชดดิ้ง + เส้นขอบลายเส้นแบบอนิเมะ ขนาดฉากไม่เกิน 10x10 หน่วย

## วิธีรันบนเครื่องตัวเอง

ต้องรันผ่าน local server เท่านั้น (เปิดไฟล์ index.html ตรง ๆ ไม่ได้ เพราะเบราว์เซอร์บล็อก ES module)

```bash
python -m http.server 8123
```

จากนั้นเปิด http://localhost:8123

## วิธีส่งงานด้วย GitHub Pages

1. สร้าง repository สาธารณะใหม่บน GitHub (เช่น `Interactive-3D-Portfolio`)
2. หน้าแรก repo กด "uploading an existing file" แล้วลากไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (index.html, โฟลเดอร์ css/, js/ และ README.md) แล้ว commit
3. เข้า Settings → Pages → Branch เลือก `main` / folder `(root)` → Save
4. รอ 1-2 นาที จะได้ลิงก์ `https://<username>.github.io/<ชื่อ-repo>/` ใช้ส่งงานรอบแรก
5. รอบส่ง Interaction (29.09.2026): กลับมาที่ repo แล้วอัปโหลดไฟล์จากโฟลเดอร์หลักของโปรเจกต์ทับ
   (index.html, css/style.css, README.md และไฟล์ใน js/ ทั้งหมด รวมถึง js/interaction.js ที่เพิ่มเข้ามา)

## แก้ข้อมูลส่วนตัวตรงไหน

แก้ไฟล์เดียว: **`js/config.js`** — ชื่อ-สกุล, รหัสนักศึกษา, มหาวิทยาลัย, คณะ, ที่อยู่, อีเมล, เบอร์โทร, โซเชียล, ทักษะ และรายละเอียดผลงาน 3 ชิ้น
ข้อมูลจะถูกวาดลงป้าย 3 มิติในฉาก (ป้ายไม้, ป้ายใต้โทริอิ, บัตรนักศึกษา, จอคอม) อัตโนมัติ

## ใส่รูปถ่ายของตัวเอง (texture)

สร้างโฟลเดอร์ `assets/` แล้ววางไฟล์ `photo.jpg` ลงไปก่อนอัปโหลด
รูปจะถูกใช้เป็น texture บนบัตรนักศึกษาหน้าโต๊ะทำงาน ถ้าไม่มีไฟล์ ฉากจะใช้รูปวาดทดแทน

## การใช้งานฉาก

- ลากเมาส์ = หมุนกล้อง, ล้อเมาส์ = ซูม, ปุ่ม ⟳ = เปิด/ปิดหมุนอัตโนมัติ, ปุ่ม ⌂ = กลับมุมมองเริ่มต้น
- ปุ่ม ♪ = เปิด/ปิดเพลงประกอบ (สังเคราะห์ lo-fi ด้วย WebAudio ในตัว หรือถ้าวางไฟล์ `assets/music.mp3` ไว้จะใช้เพลงนั้นแทน)
- ปุ่ม ☾ / ☀ = สลับโหมดกลางวัน/กลางคืน (กลางวันมีดวงอาทิตย์ กลางคืนมีดวงจันทร์+ดาว โคมไฟเรืองแสง)
- มุมขวาล่างแสดง FPS / จำนวนสามเหลี่ยม / draw call แบบเรียลไทม์

## ตารางเช็คลิสต์เกณฑ์คะแนน (รอบฉาก)

| เกณฑ์ | จุดที่อยู่ในโค้ด |
| --- | --- |
| ฉากไม่เกิน 10x10 จัดองค์ประกอบสมดุล | `js/world.js` — เกาะรัศมี 3.5 + ผิวน้ำ 9.8x9.8 ทุกวัตถุอยู่ในกรอบ -5..5 |
| ข้อมูลชื่อ-สกุล ที่อยู่ อีเมล เบอร์ มหาวิทยาลัย เป็น 3 มิติ + เนื้อหา portfolio | ป้ายไม้ ABOUT/CONTACT/SKILLS, ป้ายชื่อใต้โทริอิ, บัตรนักศึกษา, จอคอม, เฟรมผลงาน (`js/textures.js` วาดข้อความลง canvas texture) |
| ใส่รูปถ่ายของตัวเองเป็น texture | `assets/photo.jpg` → บัตรนักศึกษา (`cardTexture` ใน `js/textures.js`) |
| วัสดุ PBR อย่างถูกต้อง | ขาจอคอม/ขาเก้าอี้/ฝาโคม = `MeshStandardMaterial` metalness 0.9, จอคอม = emissive + roughness/metalness, ตัวโคม = emissive PBR (`js/materials.js`, `js/world.js`) |
| cel shading อย่างถูกต้อง | `MeshToonMaterial` + gradientMap 3 ขั้น ทั้งฉาก + เส้นขอบ inverted hull (`js/materials.js`) |
| Vertex Shader เปลี่ยนตำแหน่ง vertex แบบ realtime | ผิวน้ำเป็นคลื่นซายน์, กลีบซากุระปลิวคำนวณตำแหน่งใน vertex shader ทั้งหมด, กอหญ้า/ก้อนดอกไม้ไหวตามลม ผ่าน `onBeforeCompile` (`js/shaders.js`, `js/materials.js`) |
| ประสิทธิภาพดี รูปทรงประกอบเหมาะสม | low-poly ทั้งฉาก (~12k สามเหลี่ยม, ~135 draw call) แสดง FPS/tris/calls สดที่มุมจอ, จำกัด pixelRatio ไม่เกิน 2, shadow map 1024 |
