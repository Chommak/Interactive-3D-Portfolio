# Interactive 3D Portfolio — Anime Diorama

เว็บพอร์ตโฟลิโอ 3 มิติสไตล์อนิเมะ สร้างด้วย Three.js ล้วน (ไม่ใช้โมเดลภายนอก)
ฉากเป็นเกาะลอยน้ำขนาดไม่เกิน 10x10 หน่วย มีเซลเชดดิ้ง + เส้นขอบลายเส้นแบบอนิเมะ

## วิธีรันบนเครื่องตัวเอง

ต้องรันผ่าน local server เท่านั้น (เปิดไฟล์ index.html ตรง ๆ ไม่ได้ เพราะเบราว์เซอร์บล็อก ES module)

วิธีที่ 1 — Python:

```bash
python -m http.server 8123
```

วิธีที่ 2 — Node:

```bash
npx serve -l 8123
```

จากนั้นเปิด http://localhost:8123

## วิธีส่งงานด้วย GitHub Pages

1. สร้าง repository ใหม่บน GitHub (เช่น `Interactive-3D-Portfolio`)
2. อัปโหลดไฟล์ทั้งหมดของโปรเจกต์นี้ขึ้นไปที่ root ของ repo (index.html, โฟลเดอร์ css/, js/, assets/)
3. เข้า Settings → Pages → Branch เลือก `main` / folder `(root)` → Save
4. รอ 1-2 นาที เว็บจะเผยแพร่ที่ `https://<username>.github.io/<ชื่อ-repo>/`
   (โปรเจกต์นี้ใช้เส้นทางสัมพัทธ์ทั้งหมด จึงทำงานใต้ subpath ของ Pages ได้ทันที)

## แก้ข้อมูลส่วนตัวตรงไหน

แก้ไฟล์เดียว: **`js/config.js`** — ชื่อ-สกุล, รหัสนักศึกษา, มหาวิทยาลัย, คณะ, ที่อยู่, อีเมล, เบอร์โทร, โซเชียล, ทักษะ และรายละเอียดผลงาน 3 ชิ้น
ข้อมูลจะถูกวาดลงป้าย 3 มิติในฉาก (ป้ายไม้, ป้ายใต้โทริอิ, บัตรนักศึกษา, จอคอม) และแสดงในแผงข้อมูลตอนคลิกอัตโนมัติ

## ใส่รูปถ่ายของตัวเอง (texture)

วางไฟล์รูปชื่อ `photo.jpg` ลงในโฟลเดอร์ `assets/` (สร้างโฟลเดอร์ถ้ายังไม่มี)
รูปจะถูกละไปเป็น texture บนบัตรนักศึกษาหน้าโต๊ะทำงานทันที ถ้าไม่มีไฟล์ ฉากจะใช้รูปวาดทดแทน

## การใช้งานฉาก

- ลากเมาส์ = หมุนกล้อง, ล้อเมาส์ = ซูม, ปุ่ม ⟳ = เปิด/ปิดหมุนอัตโนมัติ, ปุ่ม ⌂ = กลับมุมมองเริ่มต้น
- ปุ่ม ♪ = เปิด/ปิดเพลงประกอบ (สังเคราะห์ lo-fi ด้วย WebAudio ในตัวอัตโนมัติ หรือถ้าวางไฟล์ `assets/music.mp3` ไว้จะใช้เพลงนั้นแทน)
- ปุ่ม ☾ / ☀ = สลับโหมดกลางวัน/กลางคืน แบบไล่ระดับเนียน ๆ (ท้องฟ้า น้ำ หมอก แสง เปลี่ยนทั้งหมด, กลางคืนมีดวงจันทร์+ดาว โคมไฟทุกดวงสว่างขึ้นพร้อม point light สีอุ่น, กลางวันมีดวงอาทิตย์)
- คลิกวัตถุที่คลิกได้ (ป้ายไม้ 3 อัน, ป้ายชื่อใต้โทริอิ, บัตรนักศึกษา, จอคอม, เฟรมผลงานลอย 3 เฟรม) = เปิดแผงข้อมูล
- กด Esc หรือคลิกพื้นที่ว่าง = ปิดแผง
- มุมขวาล่างแสดง FPS / จำนวนสามเหลี่ยม / draw call แบบเรียลไทม์

## ตารางเช็คลิสต์เกณฑ์คะแนน

| เกณฑ์ | จุดที่อยู่ในโค้ด |
| --- | --- |
| ฉากไม่เกิน 10x10 จัดองค์ประกอบสมดุล | `js/world.js` — เกาะรัศมี 3.5 + ผิวน้ำ 9.8x9.8 ทุกวัตถุอยู่ในกรอบ -5..5 |
| ข้อมูลชื่อ-สกุล ที่อยู่ อีเมล เบอร์ มหาวิทยาลัย เป็น 3 มิติ + เนื้อหา portfolio | ป้ายไม้ ABOUT/CONTACT/SKILLS, ป้ายชื่อใต้โทริอิ, บัตรนักศึกษา, จอคอม, เฟรมผลงาน (`js/textures.js` วาดข้อความลง canvas texture) |
| ใส่รูปถ่ายของตัวเองเป็น texture | `assets/photo.jpg` → บัตรนักศึกษา (`cardTexture` ใน `js/textures.js`) |
| วัสดุ PBR อย่างถูกต้อง | ขาจอคอม/ขาเก้าอี้/ฝาโคม = `MeshStandardMaterial` metalness 0.9, จอคอม = emissive + roughness/metalness, ตัวโคม = emissive PBR (`js/materials.js`, `js/world.js`) |
| cel shading อย่างถูกต้อง | `MeshToonMaterial` + gradientMap 3 ขั้น ทั้งฉาก + เส้นขอบ inverted hull (`js/materials.js`) |
| Vertex Shader เปลี่ยนตำแหน่ง vertex แบบ realtime | ผิวน้ำเป็นคลื่นซายน์, กลีบซากุระปลิวคำนวณตำแหน่งใน vertex shader ทั้งหมด, กอหญ้า/ก้อนดอกไม้ไหวตามลม ผ่าน `onBeforeCompile` (`js/shaders.js`, `js/materials.js`) |
| ประสิทธิภาพดี รูปทรงประกอบเหมาะสม | low-poly ทั้งฉาก (~10k สามเหลี่ยม, ~100 draw call) แสดง FPS/tris/calls สดที่มุมจอ, จำกัด pixelRatio ไม่เกิน 2, shadow map 1024 |
| 3D interaction (Picking) | Raycaster คลิกเปิดแผงข้อมูล + hover ขยายวัตถุ + แยกคลิกกับการลากหมุนกล้อง (`js/interaction.js`) |
| ลูกเล่นเสริมเหนือเกณฑ์ | เพลงประกอบ WebAudio + โหมดกลางวัน/กลางคืนพร้อมดวงอาทิตย์/ดวงจันทร์/ดาว/โคมไฟเรืองแสง (`js/audio.js`, `js/daynight.js`) |
